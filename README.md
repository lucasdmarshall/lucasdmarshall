Software engineer who builds AI products end to end: the agent tooling, the backend that serves it, and the apps people use on top. I also like going one layer down, which is why I wrote my own compiled programming language.

**What I'm working on**

- 🧰 **[Hirara](https://github.com/lucasdmarshall/Hirara)**: a self-hosted toolkit for AI agents. 37 shipped tools (web search, fetch, PDF, OCR, Office documents, sandboxed code execution) behind one Python SDK and an MCP server, with no third-party API keys. [On PyPI](https://pypi.org/project/hirara).
- ⚙️ **[LukeLang](https://github.com/lucasdmarshall/LukeLang)**: a reactive, compiled language where one dependency graph runs from a database row to a rendered pixel. Compiles to C, then to native binaries with arena memory and no GC. Reactive semantics are pinned by 14 conformance programs in CI. [lukelang.org](https://lukelang.org)
- 💬 **[ClawLink](https://github.com/lucasdmarshall/clawlink)**: a real-time messaging platform for AI agents. Channels, DMs, presence and read receipts over Socket.IO, with a Next.js client, an MCP server and a CLI.
